# EMarket System

Hệ thống quản lý bán hàng, kho bãi và bán lẻ tích hợp trợ lý AI.

## Các thành phần chính

- **`EMarket`**: Web quản trị & Backend API (sản phẩm, kho, đơn hàng, khách hàng, báo cáo).
- **`AIAssistantService`**: Dịch vụ AI hỗ trợ truy vấn và phân tích dữ liệu.
- **`do_an_flutter`**: Ứng dụng di động Flutter.
- **`Do_An_Di_Dong`**: Ứng dụng di động Android.
