# EMarket System Environment

Đây là mã nguồn hệ thống EMarket, một ứng dụng quản lý bán hàng và kho hàng.

Dự án gồm hai phần chính:

- `EMarket`: trang quản trị bán hàng, sản phẩm, kho, khách hàng, nhà cung cấp, đơn hàng và báo cáo.
- `AIAssistantService`: dịch vụ hỗ trợ AI, dùng để hỏi dữ liệu hệ thống và hỗ trợ phân tích thông tin.

Hệ thống có thể dùng cho cửa hàng hoặc mô hình bán lẻ nhỏ, giúp quản lý hàng hóa, theo dõi nhập xuất kho, xử lý đơn hàng và xem một số thống kê cơ bản.
